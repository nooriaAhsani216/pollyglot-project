# Pollyglot – AI Translator App
Polyglot is a modern AI app built with React + Vite that allows users to translate texts to (French, Spanish,Japanes) languages using AI-powered backend(cloudflare worker/ API);

# Features
Translate text in to multiple languages
AI-powered translations
Simlple and clean UI
Real-time response from backend API
# Tech Stack
 React
 Vite
 JavaScript (ES6+)
 Cloudflare Workers (Backend API)
 OpenAI / AI API (for translation logic)
 TailwindCss
